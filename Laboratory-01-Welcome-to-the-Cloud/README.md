# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory introduces the fundamentals of cloud computing, focusing on exploring the Linux environment, documenting system information, and organizing outputs in a GitHub repository.

## Objectives
- Understand the structure of a cloud computing workspace.
- Practice using Linux commands to gather system information.
- Create and manage Markdown documentation.
- Organize lab outputs into a public GitHub repository.

## Activities Performed
- Built a workspace folder structure with Notes and Screenshots.
- Created Markdown files (`system-information.md`, `about-me.md`, `reflection.md`).
- Ran Linux commands to collect system details.
- Pushed files and folders to GitHub for portfolio documentation.

## Linux Commands Used
- `cat /etc/os-release` → Display Linux distribution.
- `uname -r` → Show kernel version.
- `lscpu` → View CPU details.
- `free -h` → Check memory usage.
- `df -h` → Display disk space.

## Skills Learned
- Navigating and managing files in Linux.
- Writing and formatting Markdown documentation.
- Using Git and GitHub for version control.
- Structuring a professional cloud computing portfolio.
