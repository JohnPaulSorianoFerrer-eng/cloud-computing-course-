# Cloud Computing Concepts Reflections
Cloud computing has become an essential part of my daily life because many of the applications and services i use are rely on cloud technology, 
there are cloud services that i regularly use are google drive ,Facebook Messenger, YouTube, these platforms allow me to store files watch  educational
and entertainment content and communication with others anytime anywhere through the internet, Google Drive  is an example of Software as a Service (SaaS)
because it provides users with cloud-base storage and file management without requiring them to install or maintain any servers, Its deployment model is
public cloud because the service is available to anyone with google account i use google drive to save documents and access them from different devices,
making my work more convenient and organized, YouTube is also categorized as SaaS because it allows users to stream, upload, and share videos through a
web-based platform. Users can access content without managing the underlying  infrastructure or software, YouTube operates using a public cloud  deployment
model  since its services are available to millions of users worldwide through the internet i frequently use YouTube for learning new skills watching tutorials 
and accessing educational resources, Facebook Messenger is another SaaS application that enables instant communications through cloud-hosted software managed
by meta, it is also considered a public cloud service because millions of users access the platform worldwide through internet
